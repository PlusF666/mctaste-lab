# 一分钟展示讲稿

录屏前打开项目，保留“官网体验集”的来源标注。

**0—10 秒：一句话介绍**

“今天想吃什么？如果你又想回答随便，来做一个小实验。麦麦偏爱实验室不让你填问卷，先让你凭直觉选两口。”

**10—25 秒：选择**

点击开始，选几轮；演示一次“两个都想要”或“跳过”。“你的每次选择都是线索，但不是必须回答的考试。选错了也能撤销。”

**25—40 秒：结果与调整**

展示雷达图和两路推荐，拖动一个类别到更高倾向。“结果不是一句你属于某种人格。每个类别有依据，我也可以直接改主意，推荐会跟着改变，手动调整有明确标注。”

**40—50 秒：证据与导出**

展开逐轮记录，展示偏好卡导出。“心动款来自这轮我选过的单品，探索款来自这轮还没选中的候选。卡片可以带走，完整实验也能恢复。”

**50—60 秒：真实边界**

“现在公开演示使用官网真实餐品图片与名称，不冒充实时门店供应。接入麦当劳 MCP 后，可换成门店实际候选；凭据留在本机，网页不接收 Token，也不下单。”

持 Token 真实联调完成前，必须保留“官方 MCP 真实联调待完成”的准确说明。演示中的选择由讲解者操作，不应被描述成用户真实消费画像。
